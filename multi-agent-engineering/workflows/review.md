# Review Workflow

Use when the user requests analysis or review.

This file is the full Complex path. Complexity classification overrides it: Simple = Main Session reviews directly; Medium = Reviewer only unless independent exploration is needed.

Verification is optional. Skip it if there is no validation command. Main Session runs checks; do not spawn Verifier.

## Flow

1. Main Session defines review scope and acceptance criteria.
2. Reviewer examines the target.
3. Main Session checks available evidence only when a validation command exists.
4. Main Session summarizes findings.
