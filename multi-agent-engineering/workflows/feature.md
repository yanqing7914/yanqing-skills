# Feature Development Workflow

Use for adding new functionality.

This file is the full Complex path. Complexity classification overrides it: Simple = Main Session only; Medium = Explorer + Implementer, skip Reviewer/Verifier unless needed.

## Flow

1. Main Session clarifies requirements.
2. Explorer analyzes existing architecture.
3. Main Session reviews findings and creates an implementation plan checkpoint.
4. Implementer makes scoped changes.
5. Reviewer checks the implementation.
6. Main Session runs verification. Do not spawn Verifier.
7. Main Session delivers results.
