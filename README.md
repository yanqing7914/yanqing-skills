## 📦 安装方式

在 Claude Code、Codex、Cursor 等支持 Agent Skills 的工具里，直接说：

```text
帮我安装这个 Skill：
https://github.com/yanqing7914/yanqing-skills/tree/main/<skill-name>
```

把 `<skill-name>` 换成你想安装的 Skill。也可以直接下载对应目录中的 `SKILL.md`，让 Agent 按照其中的指令执行。
